# Security Policy

## Supported Versions

Only the current version is supported with security updates.

| Version | Supported |
| ------- | --------- |
| Current | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately to the repository owner through GitHub. Include the affected area and steps to reproduce. Do not publish secrets, personal data, or an exploitable proof of concept in a public issue.
